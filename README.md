## IDLE 로 가져가 직접 돌려 보기

화면의 파이썬 코드는 오른쪽 위 **복사** 버튼으로 그대로 가져갈 수 있다. `import numpy as np` 가 빠진 코드에는 복사할 때 자동으로 붙여 준다. 장 맨 아래에는 **그 장의 코드를 전부 모아 `.py` 파일로 저장**하는 버튼이 있다.

```
1) python.org/downloads 에서 파이썬 설치 (Add python.exe to PATH 체크)
2) pip install numpy
3) 저장한 .py 를 우클릭 → Edit with IDLE
4) F5
```

`.py` 로 모을 때 다음을 자동으로 처리한다 — 그래서 **그대로 돌아간다**(`npm run test:idle` 이 실제 파이썬으로 검증한다).

- 실습 데이터가 필요한 장에는 관절염 데이터를 리터럴로 함께 넣는다 (CSV 파일이 없어도 된다)
- 배포하지 않는 파일을 읽는 코드, 주피터·Colab 전용 코드는 주석으로 넣는다
- 일부러 에러를 보여 주는 예제가 있어도 멈추지 않게 블록마다 `try/except` 로 감싼다
- 맨 표현식을 `print()` 로 감싼다 — 주피터와 달리 IDLE 편집창은 자동 출력하지 않는다

블록 하나만 복사했다면 IDLE **셸**(`>>>` 창)에 붙여넣는 것이 편하다. 셸은 값만 쓴 줄도 결과를 바로 보여 준다.

## 이 실습장이 특별한 이유 — 브라우저에서 도는 미니 NumPy 엔진

화면의 숫자는 미리 적어 둔 값이 아니라 **그 자리에서 계산한 결과**다. 슬라이더를 움직이면 진짜 값이 따라온다.

핵심은 [`webapp/src/core/nd.js`](webapp/src/core/nd.js) 가 NumPy와 똑같이 **`(buffer, shape, strides, offset)`** 네 값으로 배열을 모델링한 점이다. 덕분에 글이나 그림으로는 전달되지 않는 것들을 **실행으로** 보여 줄 수 있다.

- **뷰(view)는 원본과 같은 메모리를 본다** → 뷰를 고치면 원본이 바뀌는 것을 메모리 칸 색으로 확인
- **브로드캐스팅은 복사하지 않는다** → 늘어난 축의 `stride` 가 실제로 `0` 이 되는 것을 확인
- **`.T` 는 strides 만 뒤집는다** → 값이 아니라 보는 방식만 바뀐다는 것을 확인

### 엔진이 실제 NumPy와 다른 점 (정직하게)

- **`.strides` 는 원소 단위**로 보여 준다(NumPy는 바이트 단위). `바이트 = 원소 × itemsize` 다.
  같은 `a.T.strides` 가 미니 엔진 `(1, 4)`, 11장 Pyodide 탭 `(4, 16)`, 64비트 데스크톱 NumPy `(8, 32)` 로 나온다 —
  Pyodide는 WASM 32비트라 기본 정수가 `int32` 이기 때문이다. 11장에 이 표를 넣어 설명했다.
- `np.random.*` 은 알고리즘이 달라 `seed` 를 줘도 NumPy와 같은 수열이 나오지 않는다.
- `np.empty` 는 초기화하지 않은 메모리를 흉내 낸 것이다(원래 예측 불가한 것이 요점이다).
- 아주 큰 정수와 실수의 마지막 자리는 JS 수 표현 한계로 어긋날 수 있다.
- `matmul` 은 2차원까지만 지원한다.

11장에서 같은 코드를 **진짜 NumPy(Pyodide)** 로 돌려 직접 맞대어 볼 수 있다.

## NumPy 2.x 기준

원본 수업자료는 2024년 3월 NumPy 1.x 기준이라 지금 실행하면 오류가 나는 부분이 있다. 바로잡고 무엇을 왜 고쳤는지 `numpy.md` 12.5절에 정리했다.

- `np.NaN`, `np.Inf`, `np.float_`, `np.int` → **2.0에서 삭제.** `np.nan`, `np.inf` 를 써야 한다.
- `np.std` 기본은 `ddof=0`(모표준편차) — 통계 시간에 배운 표본표준편차와 다르다.
- `np.round` 는 **은행가 반올림**: `np.round(0.5)` → `0.0`, `np.round(2.5)` → `2.0`.
- NumPy 2.2부터 요약된 배열 repr 에 `shape=(...)` 가 붙는다.

### 손대기 전에 알아 둘 것

- **ES 모듈 문법(`import`/`export`) 금지.** `numpy-lab.html` 단일 파일 배포본에 인라인되므로 깨진다. 모든 소스는 `window.X` 에 붙는 IIFE 다.
- `webapp/src/core/app.js` 는 **모듈보다 먼저** 로드되어야 한다(`window.Lab` 을 정의한다). 순서가 뒤바뀌면 모든 장이 조용히 등록되지 않는다.
- `render(root)` 는 장을 다시 방문할 때마다 호출된다. 모듈 전역에 가변 상태를 두면 두 번째 방문에서 깨진다.
- `nd.js` 를 고쳤으면 반드시 `npm test` 를 돌려라.
